# Changelog

## 0.1.0

- First release. Shows the VBA macros of .xlsm, .xlsb, .xls, .xltm, .xlam, .docm, .dotm, .doc, .pptm, .ppt and vbaProject.bin files without Office.
- Module list (document, standard, class and form modules), source with line numbers and VBA colors, search across all modules, module details (type, size, procedures, attributes), copy, and open a module as read-only text.
- Project overview with references, code page and VBA password state. Lists Excel 4.0 macro sheets, with their formulas in OOXML workbooks.
- Read-only: no macro runs, nothing is written to the file, no network calls.
- Zovo Pro tools: Export all modules; Macro security scan; Compare macros (1 free try each).
