# Free Zovo tools for the rest of an Office file

- XLSX Viewer: the sheets of .xlsx, .xlsm and .xls workbooks as tables.
- DOCX Viewer: Word documents as pages.
- PPTX Viewer: slides of .pptx and .ppt files.
- Hex Viewer: the raw bytes of any file, for example a vbaProject.bin.

Each link opens the extension's page. Nothing installs until you choose Install there.
